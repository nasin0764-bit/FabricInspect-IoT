\subsection{Computational Resources}\label{sec:res-resources}
Table~\ref{tab:resources} summarises cost. On one core the station model needs 36.1\,ms per frame (median; p95 40.3\,ms), \ie it sustains about 27 frames/s, more than five times the 5\,frames/s inspection rate, and it requires no deep-learning runtime. Its serialised profile is only 5.0--6.1\,kB, whereas a PatchCore-lite memory bank occupies 1.1--1.3\,MB (about 200$\times$ more) and a PaDiM model (per-position covariances) 165\,MB in memory, which rules PaDiM out for distribution to stations. With eight threads the edge model scores a single frame in 16--20\,ms including JPEG decoding; micro-batching raises the edge throughput $\mu$ from 64 frames/s at $b=1$ to 96 frames/s at $b=8$. Fitting any model on $k=20$ shots takes at most about 2\,s, so a new fabric is ready for inspection essentially as soon as its frames are captured.

\subsection{Ablation of the Station Descriptor}\label{sec:res-ablation}
Table~\ref{tab:ablation} isolates the components of the 30-dimensional descriptor at $k=20$. Removing the Lab chroma statistics costs 0.029 image AUROC and 0.065 AUPRO---colour defects (stains, contamination) are invisible to a greyscale texture model---and removing the Gabor bank altogether costs 0.039 and 0.108. The local standard deviation of the Gabor energies contributes mainly to localisation (+0.017 AUPRO). Six orientations instead of four improve image AUROC by 0.016 at 40\,\% more dimensions and filter cost; a smaller pooling window helps detection but hurts localisation. We keep the 30-dimensional configuration as a compromise between accuracy, compute, and profile size, but note that the station model leaves room for fabric-specific tuning.
