\section{Conclusion}\label{sec:conclusion}
We presented FabricInspect-IoT, a few-shot, label-free fabric inspection service for networked seaming stations, and characterised it as an IIoT system. A fabric is learned from ten defect-free frames in about a second; a 6\,kB station model and a ResNet-18 nearest-neighbour edge model are fitted together, and both obtain their decision thresholds by leave-one-out scoring of the shots, without any defect example. With these thresholds, the edge model reaches F1 0.935 at 4.3\,\% false alarms on four of five MVTec~AD textures, while the fifth (grid) exposes the limits of ten-shot calibration. Confidence-gated offloading retains 99\,\% of the edge-only F1 while sending only half of the frames to the edge and lowers the station-only false-alarm rate from 28\,\% to 8\,\%; the gate adapts its offload rate to the fabric (23--81\,\%) using only the label-free thresholds. A trace-driven simulator, validated against a live testbed with a production MQTT broker, shows that on Wi-Fi a single CPU edge server meets a 200-ms decision deadline for 24 stations with the gate versus 16 without it (8 vs.\ 4 for a server twice as slow), while uplink traffic per station drops by 39\,\%; on a 1-Mbit/s uplink only locally decided frames meet the deadline, which makes the station model indispensable there. Retained MQTT messages distribute a new fabric model to any number of stations within 15\,ms on Wi-Fi.

Future work will validate the system on images logged at the seaming machines, port the station model to the machines' Android controllers, add operator feedback to refine the LOO thresholds, and extend the gate to adapt $\alpha$ to the instantaneous edge load and uplink quality.
